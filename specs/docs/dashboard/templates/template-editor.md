# Compose with the Template editor

> Learn how to write reusable transactional email Templates in the Dashboard editor

## Template editor

Resend's no-code Template editor is built into the Dashboard to allow anyone on your team to create and update reusable transactional emails.

You can drag and drop an existing file, use slash commands to add content without leaving the keyboard, or compose in Markdown.

The included AI assistant can compose common transactional emails for you, such as welcome messages and password resets.

## Markdown Support

The editor supports writing your emails using Markdown headings, lists, italic, bold, links, and quotes.

If you copy and paste content from other rich or plain text applications, the editor maintains formatting consistency.

## Custom Styling

You can customize the look and feel of your email by changing **global styles** such as the background color, link color, and container size, allowing you to create emails aligned with your brand identity.

To do this, click on **Styles** at the top left of the Template editor. You can edit specific images or lines of texts by selecting or highlighting them prior to clicking on **Styles**.
